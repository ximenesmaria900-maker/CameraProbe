# CameraProbe — GigE Vision камера & диагностический зонд для Android

**CameraProbe** превращает Android-смартфон (OnePlus, Xiaomi, Samsung и др.) в промышленную машинную камеру **GigE Vision** с поддержкой протокола **GVCP / GVSP** для прямого подключения в **Hikrobot MVS**, **Halcon**, **LabVIEW** или OpenCV.

Проект разработан для задач калибровки, 3D-сканирования и лазерной триангуляции.

---

## 🚀 Ключевые возможности

### 1. Промышленный протокол GigE Vision (Hikrobot MVS)
- **GVCP (GigE Vision Control Protocol):** UDP порт `3956`. Автоматическое обнаружение устройства в Hikrobot MVS, чтение XML-дескриптора камеры (GenICam), управление экспозицией и форматом.
- **GVSP (GigE Vision Streaming Protocol):** высокоскоростной стриминг несжатых кадров `Mono8` (640×480) по UDP со скоростью до 30 кадров/сек.

### 2. Полная синхронизация пространственной ориентации (1:1)
- Непрерывная аппаратная синхронизация гироскопа/акселерометра устройства (`fullSensor`).
- Истинное соответствие 1:1 между:
  1. Физическим положением смартфона в пространстве (0° портрет, 90° альбомная вправо, 180° перевернутый портрет, 270° / -90° стенд/альбомная влево).
  2. Превью кадра на экране смартфона (`TextureView`).
  3. Отправляемым в MVS кадром (`Mono8` буфер с математически точной перекладкой YUV-пикселей без инверсий верха/низа или зеркалирования).

### 3. Динамический выбор камер и оптических модулей
- Автоматическое сканирование Camera2 API на устройстве.
- Отображение всех доступных физических модулей (основной сенсор, фронтальная, сверхширокоугольная, телефото) с реальным разрешением матрицы в мегапикселях (например, 4096×3072, 12.6 MP).

### 4. Динамический зум (1×, 2×, 4×, 8×)
- Мгновенное аппаратное кропирование области сканирования на сенсоре с сохранением высокой детализации.

### 5. High-Res Sensor ROI Extraction (Выделение ROI на сенсоре)
- При работе сенсора в высоком разрешении в поток GigE Vision транслируется точно заданная область интереса (ROI 640×480).
- Интерактивный видоискатель на экране отображает границы ROI рамкой с бейджем разрешения, поддерживая центрирование и перемещение области сканирования.

### 6. Встроенные лабораторные тесты оптики
- **ISP Test:** оценка вмешательства встроенного процессора обработки изображений (сравнение гистограмм RAW vs YUV, расстояние Бхаттачарьи).
- **Focus Stability:** измерение флуктуаций фокуса по вариации оператора Лапласа на серии из 30 кадров.
- **Rolling Shutter:** детектирование наклона лазерной линии при движении методом преобразования Хафа.
- **HTTP Экспорт:** встроенный NanoHTTPD сервер на порту `8080` для выгрузки тестовых DNG (RAW16), JPEG и телеметрии.

## 📦 Быстрый старт (Установка готового APK)

Готовый скомпилированный APK находится в репозитории:
👉 **[`apk/CameraProbe.apk`](apk/CameraProbe.apk)**

Установка через ADB:
```bash
adb install -r apk/CameraProbe.apk
```

## 🛠️ Сборка из исходников

### Требования:
- Android Studio Ladybug / Hedgehog или новее
- Android SDK 35 (Android 15 / 14)
- JDK 17+
- NDK не требуется (чистый Kotlin + Android Camera2 + OpenCV SDK)

### Сборка через командную строку:
```bash
# Windows
gradlew.bat assembleDebug

# Linux / macOS
./gradlew assembleDebug
```
Собранный APK будет находиться в `app/build/outputs/apk/debug/app-debug.apk`.

## 🌐 Подключение к Hikrobot MVS

1. Подключите смартфон и ПК с Hikrobot MVS к одной локальной сети (по Wi-Fi 5 ГГц либо через USB Ethernet-адаптер / RNDIS).
2. Запустите приложение **CameraProbe** на смартфоне.
3. В Hikrobot MVS нажмите кнопку **Обновить список камер** (Discover).
4. Камера отобразится в списке как GigE Vision устройство с именем `CameraProbe` и серийным номером устройства.
5. Нажмите **Connect** и запустите непрерывный захват (**Start Grabbing**).
